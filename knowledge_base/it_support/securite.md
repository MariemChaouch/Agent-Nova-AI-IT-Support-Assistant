## 1. PHISHING — RECONNAÎTRE ET RÉAGIR

### Comment reconnaître un email de phishing
- Expéditeur suspect (domaine inconnu ou mal orthographié)
- Urgence artificielle : "Votre compte sera bloqué dans 24h !"
- Liens qui ne correspondent pas à l'URL réelle (survoler le lien)
- Demande de mot de passe ou d'informations personnelles
- Fautes d'orthographe inhabituelles
- Pièce jointe non attendue (.exe, .zip, .docm)

### Que faire si tu reçois un email suspect ?
1. **Ne clique PAS** sur les liens
2. **Ne télécharge PAS** les pièces jointes
3. **Ne réponds PAS** à l'email
4. Transfère l'email à **support@izen.tn** avec le sujet "PHISHING SUSPECT"
5. Supprime l'email de ta boîte de réception

### Si tu as déjà cliqué sur un lien suspect
1. **Déconnecte-toi du réseau** immédiatement (Wi-Fi + câble)
2. Appelle IT en urgence : **Poste 101**
3. Ne touche plus au PC jusqu'à intervention IT

## 2. MALWARE / VIRUS — PROCÉDURE D'URGENCE

### Signes d'infection
- PC soudainement très lent
- Popups publicitaires inhabituels
- Antivirus désactivé sans raison
- Fichiers cryptés ou renommés
- Activité réseau intense sans raison

### Procédure d'urgence
1. **ÉTAPE 1** : Déconnecte le PC du réseau (enlève le câble Ethernet, coupe le WiFi)
2. **ÉTAPE 2** : N'éteins PAS le PC (conserver les preuves)
3. **ÉTAPE 3** : Appelle IT immédiatement → **Poste 101**
4. **ÉTAPE 4** : Ne transfère aucun fichier depuis ce PC

### Scan antivirus manuel (si IT autorisé)
- Windows Defender : Sécurité Windows → Protection contre les virus → Analyse complète
- Délai : 30-60 minutes pour une analyse complète

## 3. MOTS DE PASSE — BONNES PRATIQUES

### Règles de la politique de sécurité IZEN
- **Longueur minimum** : 8 caractères
- **Composition** : majuscule + minuscule + chiffre + caractère spécial
- **Renouvellement** : tous les 90 jours (rappel automatique)
- **Réutilisation** : les 10 derniers mots de passe ne peuvent pas être réutilisés
- **Partage** : INTERDIT — chaque employé est responsable de son compte

### Gestionnaire de mots de passe recommandé
- Utilise un gestionnaire de mots de passe approuvé par IT
- Contact IT pour la liste des outils approuvés

## 4. AUTHENTIFICATION MULTI-FACTEURS (MFA)

- MFA activé pour : VPN, email, accès applications critiques
- Application MFA : Microsoft Authenticator (recommandé)
- En cas de perte du téléphone MFA → contacter IT **immédiatement** : Poste 101
- IT peut générer un code de secours temporaire
